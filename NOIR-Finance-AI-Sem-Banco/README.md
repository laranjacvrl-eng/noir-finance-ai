NOIR Finance AI v2

- Interface escura e minimalista.
- Nubank e Inter já aparecem como contas iniciais.
- Você pode escolher o banco em cada lançamento.
- Finance AI local: interpreta comandos simples e consulta seus próprios dados.
- Lançamentos, contas, cartões, orçamentos, metas e recorrentes.
- Exportação XLSX com várias abas usando SheetJS.
- Backup JSON.
- Tudo fica salvo no localStorage deste navegador.

IMPORTANTE:
Esta versão não acessa contas bancárias reais. Nubank/Inter são contas cadastradas manualmente.
A “IA” é um interpretador local, sem envio dos seus dados para um serviço externo.
Para usar a exportação Excel, o navegador precisa carregar a biblioteca SheetJS pela internet na primeira abertura.
